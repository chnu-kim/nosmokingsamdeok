# 삼덕이의 금연 챌린지

삼덕이의 금연 챌린지 현황 페이지 + OBS 오버레이 위젯.

**라이브 URL**: https://chnu-kim.github.io/nosmokingsamdeok/

---

## OBS 오버레이 설정

방송 화면에 챌린지 진행 상황을 띄우는 위젯입니다.

### 브라우저 소스 추가

1. OBS에서 **소스 추가 → 브라우저** 선택
2. 아래 값 입력:

| 항목 | 값 |
|------|-----|
| URL | `https://chnu-kim.github.io/nosmokingsamdeok/overlay/` |
| 너비 | `300` |
| 높이 | `120` |
| 배경색 | 체크 해제 (투명) |

3. **확인** 후 화면 원하는 위치에 배치

### 커스터마이저

오버레이 디자인을 직접 조정하고 URL을 복사할 수 있습니다.

**커스터마이저**: https://chnu-kim.github.io/nosmokingsamdeok/overlay/customize/

### 템플릿 종류

| 템플릿 | 설명 |
|--------|------|
| `default` | 날짜 + 최고 기록 |
| `minimal-serif` | 세리프 폰트 한 줄 |
| `big-number` | 일차 숫자 크게 |
| `one-line` | 한 줄 텍스트 |
| `bar-only` | 일차 텍스트만 (가장 미니멀) |

### 최고 기록

`default` 템플릿에서는 라벨 우측에 최고 기록(이전 시도 중 가장 오래 유지한 일수)을 작게 함께 보여줍니다. 진행 일수가 최고 기록을 넘어서면 "최고 기록 N일" 대신 "신기록 (+N일)"로 바뀝니다.
